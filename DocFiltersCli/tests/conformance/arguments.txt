# ---------------------------------------------------------------------------
#  docfilters CLI — the argument surface
#
#  Shared by the C#, Python, Java and C++17 implementations. This file is the
#  authority on which arguments exist on which command, written from the CLI design
#  document rather than dumped from any implementation.
#
#  That direction matters: a file generated from the C# build can only prove the
#  other three agree with C#. This one proves all four agree with the spec, so a
#  argument nobody implemented still fails.
#
#    = argument  <template>  <arity>
#
#    template  as written on the command line; short and long forms separated
#              by | exactly as the design document lists them
#    arity     none      a switch, takes no value
#              single    takes one value; a later occurrence replaces an earlier
#              multiple  repeatable; every occurrence is kept
#
#  --help and -h are deliberately absent: every parsing library provides them,
#  each formats them differently, and help text is not part of the contract.
# ---------------------------------------------------------------------------
